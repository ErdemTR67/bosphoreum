## Référence de marque

### brand/palette-and-type-reference.png

Cette image devient la référence actuelle pour :

- l’atmosphère typographique ;
- le contraste des grands titres ;
- les quatre couleurs principales ;
- l’utilisation du noir et du blanc.

Les noms et codes écrits à l’intérieur de la planche sont incohérents.

Les couleurs à retenir sont celles des aplats visuels :

- #8074C8
- #4B4452
- #B1A8B9
- #9470BA

La police exacte doit encore être identifiée et validée avant intégration.

Ne pas reproduire les formes arrondies de la planche comme élément obligatoire
du site. Elles servent ici à présenter les couleurs, pas à définir le système
de formes de Bosphoreum.

### Logos

Les exports actuellement disponibles dans `public/brand/` sont tous des PNG
transparents de 4000 × 4000 px.

#### Version noire

Dossier : `public/brand/bosphoreum_black_version/`

- `text.png` : mot-symbole « Bosphoreum » noir, sans illustration ;
- `text_bridge.png` : mot-symbole noir superposé à une illustration
  monochrome d’un pont suspendu ;
- `text_bridge2.png` : mot-symbole noir superposé à une illustration détaillée
  du pont dans des tons bleu-gris ;
- `text_bridge_sea.png` : même composition avec un paysage marin bleu-gris.

#### Version claire

Dossier : `public/brand/bospho_light_version/`

- `text.png` : mot-symbole « Bosphoreum » blanc, sans illustration ;
- `bosphoreum_light01.png` : mot-symbole et pont suspendu blancs ;
- `text_bridge.png` : mot-symbole blanc avec une illustration du pont dans des
  tons clairs et bruns ;
- `text_bridge_sea.png` : même composition avec un paysage marin brun.
